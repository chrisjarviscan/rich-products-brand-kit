# Rich Products brand kit

Everything Claude needs to make on-brand work for Rich's: the rules, the logos, and ready-to-use color and font settings.

| What | Where |
|---|---|
| Full brand rules | `BRAND.md` |
| Logos (website SVG, tagline lockup, language versions, RPC) | `assets/logos/` |
| Rule diagrams (lockups, clear space, minimum size, placement, misuse) | `assets/rules/` |
| Other pages from the brand portal | `assets/reference/` |
| Colors and fonts for code | `tokens/colors.json`, `tokens/richs-brand.css` |
| Claude skill | `skills/rich-brand/SKILL.md` |

## Connecting to Claude

**claude.ai (either your Realized Worth or personal Claude account):** open a Project, choose Add content, then GitHub, sign in to GitHub as `chrisjarviscan` if asked, and pick this repository. Add `BRAND.md`, `skills/`, `tokens/` and `assets/rules/`. Each Claude account connects to GitHub separately, so do this once per account.

**As a skill:** download `skills/rich-brand/` as a zip and upload it under Customize, then Skills.

**Claude Code:** clone the repo; `CLAUDE.md` tells Claude how to use it.
